## 来源登记

### Q1 Little 关系与统计边界

原始入口：[MIT《Urban Operations Research》4.4 Some Important Relationships in Queueing Theory](https://web.mit.edu/urban_or_book/www/book/chapter4/4.4.html)。大学原始教材正文；本入口未提供 DOI。状态为 **body_read**；核读 (4.6)—(4.13) 的推导说明及其后关于队列边界、优先级、有效到达的注释。旧 HTML 部分公式是图片，页面可读不代表所有图片已逐式核验。许可：公开可读，所读页未核到明确再分发许可。

- 适用关系：`L=λW`；队列内另有 `Lq=λWq`。L/Lq 为平均项目数，λ 为同一边界的有效进入率，W/Wq 为对应停留/等待时间；率与时间须用同一时间基准。
- 前提与方法：长期平均量存在、统计边界及进入/离开口径一致。可用作在制品、吞吐与周期的交叉核对，不要求先套 M/M/1；退回、放弃和拒绝进入须明确处理。
- 迁移反例：用包含服务中的 L 配仅排队的 Wq；把外部提交量当被系统接受量；把工作日和日历日混算。λ=0 时不能通过除法求 W。
- 能支持：队列核算关系及口径；不能支持：仅由均值证明业务拥堵成因、最佳人力或干预后的效果。来源不存在“提高利用率一定缩短等待”的一般结论。

### Q2 M/M/1 的随机假设与稳定边界

原始入口：[同书 4.6.1 Case 1 One Operator Infinite Number of Lines](https://web.mit.edu/urban_or_book/www/book/chapter4/4.6.1.html)。状态为 **body_read**；核读开头三项假设、(4.35) 稳定性讨论、(4.38) 系统时间及等待时间说明。作者教材无本节 DOI。许可：公开可读，明确再分发许可未核；公式图片未做独立 OCR/逐图校验，文字给出期望系统时间 `[μ(1−ρ)]^-1`，下列等价式和 Wq 是在声明假设下的代数整理。

- 公式与单位：`ρ=λ/μ`、`W=1/(μ−λ)`、`Wq=W−1/μ=λ/[μ(μ−λ)]`、`L=λW`。λ、μ 均为项目/时间，ρ 无量纲，W/Wq 为时间。
- 前提：单服务者、泊松到达、独立指数服务、FCFS、无限等候容量、不因等待离开；常参数稳态要求 `0≤λ<μ` 且 `μ>0`。μ 是服务能力参数，不是观察期完成量的任意替代。
- 方法与反例：用模型比较能力与等待的权衡，但需核数据是否适配；`λ=μ` 也不满足该稳态式，不能只拒绝 `λ>μ`。批量/重入、不同优先级或时变能力不能仅凭相同均值直接套用。
- 能支持：假设模型内的演算及边界；不能支持：审核团队实测周期、审核质量和实际增员效果。有限容量可能稳定但有丢失，它属于另一模型，不能把 M/M/1 无限队列的拒绝解释成所有系统都会无限增长。

### Q3 排队方法的用户结果与名词核对

原始入口：[MIT 15.760 Class 8 Basic Concepts in Queueing 讲义 PDF](https://ocw.mit.edu/courses/15-760a-operations-management-spring-2002/e6c66bef8fc37c9f4928ea8f816895ab_lecture8_feb22.pdf)。状态为 **body_read**；核读 PDF 第 7—11 页的利用率、Little 关系和拥堵非线性，第 13 页的能力/等待成本权衡。以 PDF 物理页 1 起计；并非重新核验所有图像。无本讲义 DOI；公开大学课程材料，具体许可和图形再利用条款本轮未核，不复制页面。

- 适用量和方法：到达率 λ、服务率 μ、等待时间与能力成本；可作为提出“缩短周期同时保留质量/成本约束”的方法线索。
- 假设与失效：讲义部分页用 L/W 表示队列量，与 Q1/Q2 的全系统量命名不宜直接拼接。必须按该页的定义区分 `Wq` 与 `W`；不能仅凭字母相同认定来源冲突。

### T1 集总热模型与 RC 自由衰减

原始入口：[MIT Unified Engineering 18.3 Transient Heat Transfer](https://web.mit.edu/course/16/16.unified/www/FALL/thermodynamics/notes/node129.html)。状态为 **body_read**；核读空间等温近似、(18.14)—(18.18)、时间常数及 Figure 18.7 后 RC 方程说明，公式由页面的数学替代文本读取。大学原始讲义，无本节 DOI；公开可读，明确再分发许可未核。

- 公式：`Cth·dθ/dt=−θ/Rth`，`θ=T−T∞`，`Cth=m·cp`，`Rth=1/(hA)`；理想 RC 为 `Ce·dV/dt=−V/Re`，时间常数各为本侧 R·C。θ:K、Cth:J/K、Rth:K/W；V:V、Ce:F、Re:Ω；两侧时间常数均为 s。此处 cp 是比热，非电容。
- 前提与方法：热侧内部温差可忽略、环境恒定、常参数、无热源，电侧理想孤立 RC 且 R/C 为正；可借用一阶响应与时间常数。来源以小 Biot 数说明集总近似，本语料不自行规定一个适合所有物体的经验阈值。
- 迁移与失败：各自令 `u=x/x0`、`s=t/τ`，非零初值下得到同一归一模型；**不是 K=V 或物理能量等同**。两侧初值均为零时分别使用未归一方程及恒零解，不除以零；一侧为零、另一侧非零时，不能宣称同一初值问题等价。负温差可衰减趋零；环境时变、内部梯度、辐射非线性、外部输入或电感会改变原模型。
- 能支持：声明条件下两模型的对应；不能支持：任意实物符合该模型、拟合即证明机制、无条件全局同构。多节点热网络不在当前单节点检查范围。

### L1 局部恢复与预警误差的模型比较

作者原文：[Boettiger 与 Hastings 2012 Quantifying Limits to Detection of Early Warning for Critical Transitions 的 HTML 入口](https://arxiv.org/html/1204.6231)；[已实际核定的固定书目版本 arXiv:1204.6231v1](https://arxiv.org/abs/1204.6231v1)，作品持久标识 DOI [10.48550/arXiv.1204.6231](https://doi.org/10.48550/arXiv.1204.6231)。状态为 **body_read**：重点读 §2 零模型问题、§3 模型与 (4)、(8)、(9)、§5 比较及 §6 讨论。无后缀 HTML 本次显示 v1，但入口本身未固定版本；DOI 也是作品标识，不是版本锁。HTML 显示 CC BY 3.0；该观察不自动覆盖期刊版及第三方附图，本仓库不保存全文。

- 关系与单位：论文稳定零模型使用均值回复过程。令 δ 为条件均值相对**固定平衡值**的偏差，在该局部常参数说明中 k 为固定的正数（`k>0`），可整理为 `dδ/dt=−kδ`、`τ=1/k`；这不是随机样本轨迹本身满足的确定方程。δ 单位随被测变量 U，k 为时间^-1；在本项目允许范围使用 one/K/V 与 s。此单位映射为本语料的量纲解释，不声称论文只研究这些物理量。
- 前提与方法：局部线性、稳定回复、适当采样与噪声假设；论文用模型比较和 ROC 表达误报/漏报权衡。OU 随机方差、拟合、ROC 的实际计算未因此加入当前允许表。
- 反例：外部驱动、噪声变化、非线性范围扩大或测量变化可以改变观测；仅统计量上升不识别机制。
- 能支持：局部恢复与统计识别应分开评估；不能支持：任何新现象接近突变、固定预警阈值、具体日期或投资预测。本轮未复现其数值与数据。

| 家族 | 本轮可支持的最小内容 | 应保持的区分 | 必须拒绝的升级 |

| 局部恢复/证据冲突 | 同时给出“指标上升可能符合恢复变慢”和“机会事件也出现相似统计”两条原文 | 解释机制与识别层次，报告竞争解释；不是强行决定两论文必有一错 |
| 局部恢复/调用失败 | 将 M1 获取在专属测试适配器中设为受限，同时 L1/L2 可读取；或综合步骤在取得来源后失败 | 保留合法已读证据，将该次 M1 访问标 restricted；失败保持检查点，不标完整综述，不绕门禁；不改历史成功访问 |

来源冲突验收还需一个真正不可在当前范围解释的对照：两个经核原文对相同对象、条件和指标给出不同结果时，保留两侧支持范围与无法解决项，而不是用模型语气裁决。该对照可用明确标注的合成测试正文验证机制，但不能冒充新增真实科学来源。

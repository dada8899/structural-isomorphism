# U2 有限财务执行器

日期：2026-10-17；策略：`financial-scenario-v1-candidate`。本模块是 **bounded pure evaluator**，不是 OS sandbox，也没有 API 授权、数据库、模型、计费或原文真实性验证。所有新数值测试均为 synthetic，不是字节财务数据或正式预测。共享接线、独立数学／会计审阅与真实任务验收另行完成。

## 输入与来源

调用者单独提供不可变 `SourceRegistry`；请求只引用观测 ID，不能提交一份自称 disclosed 的事实表。受控观测保留指标、group/app/segment 范围类型、期间、原币种／单位、会计口径和证据级别；集团基线拒绝 app／segment。来源与层级仍由调用者负责，类型验证不证明原文为真。

`curated_record` 必须有整理表 digest、固定 commit、entry／行定位和人工读取范围，raw_response_digest、extracted_text_digest 与 retained_original_ref 必须为 null。包括旧 87e564／f8a8 历史表在内，整理表摘要不能充当原文摘要。确实保留原文的 `historical_original` 与 `live_original` 是不同 kind，必须由受控调用者提供真实原文／提取摘要及不含私有路径的 opaque 原文引用；不能强制所有历史一律无原文。后来取得 live 原文须新建快照关联，不回填旧 curated 记录。

情景参数始终另标假设。与已知观测不符时，不能通过重复写数值变成事实；必须拒绝，或显式 independent 并保留原锚点与理由。无证据支持的参数只呈现机械条件演示，不能包装为可信基准预测。原始观测／参数字符串不被显示舍入覆盖。

## 固定计算范围

- 只支持 CNY/USD、unit/thousand/million/billion，计算表统一百万单位。历史流量换汇仅同期间、同方向的受控 period-average FX；不能用即期或未来假设替历史。未来 FX 单独声明、正值、期间／方向精确匹配，不自动反向或找邻近汇率。
- 信息截止必须位于固定桥年2026；2026E 营收为已取得年初至中期的集团金额，加紧接其后的剩余期间显式情景，不把半年乘二称实绩。增长作用于原币营业规模，连续计算 2027–2031 五完整年，再按各年明示 FX 转人民币；不会在人民币值上把 FX 与增长重复复利。缺 FX 保留原币结果与对应换算缺口。
- 营业利润为营收减明确成本／费用，加明确经营调整。成本可绝对额或收入比例；比例大于100%和亏损合法。成本覆盖必须明确基础成本、基础费用、共用成本、折旧、SBC，重复包含即拒绝；未覆盖项必须显式情景排除，否则利润不足。缺值不是零。CAPEX 不入经营费用，净利不替营业利润；历史利润缺失不阻断未来完整成本条件下的计算，也不回填历史利润／margin。
- 业务分类只接受声明互斥的变现维度，不能混加 App/地区/GMV。分部可绝对额或收入占比；已知合计大于集团拒绝，不用负未分配配平。未建模收入保留未分配，缺名目不额外加总；全部未分配不是构成任务完成。零营收时计算占比分母为零，返回 null。
- 单参数敏感性仅增长、成本或未来 FX，固定其余输入与 registry；每个点另有输入摘要，不自动拟合、插值、蒙特卡洛或标概率区间。表与图从同一不可变结果快照读取，图不另算财务，不连接缺失点。

原币与目标币相同的结果快照用 `native.same_as=target` 去重存储；年度单元格继承该行的原币／目标币与根百万单位，share 仍显式为 ratio，省略的 basis 仅代表 derived_conditional、省略 reasons 仅代表空数组。`FinancialSnapshot.table()` 还原这些明确默认值，返回完整且独立复制的表视图；图读取同一 target 单元格，摘要绑定紧凑快照。不同币种仍分别保留，不能用存储优化冒充汇率转换。参数的理由、原值、单位和锚点保留在 request_snapshot，统一标 scenario_assumption，不重复复制一份参数依据。

## 数值与资源边界

Decimal 使用隔离的50位 Context；百万单位显示量化6位、HALF_EVEN，内部值与原始输入另存，分部显示舍入差额单列，不塞入未分配项。先限制数值字符串≤64字符、24有效位、指数与非零数量级在±18，输入／中间绝对值≤1e18，再构造和计算；拒 bool、float、NaN、无穷和任意表达式。

场景≤3、桥年2026加未来5年、类别≤8、来源≤16、观测≤64、历史／未来 FX 各≤16、成本行≤16、敏感点≤21；输入（含 registry）和完整导出各≤128 KiB。单次最多5000个计量步骤，分步检查2秒 deadline；这是合作式检查，不是抢占式 CPU／内存硬隔离。超限整次拒绝，不截断后伪装成功。返回的是绝对量表和 JSON 图 spec，不绘制或发布正式预测。

这些上限同时生效，不承诺全部数量上限满载时仍能装入字节／操作预算；复杂跨币或敏感性组合可能明确超限，不能暗降精度、删来源或扩大资源。

本轮验证通过真实纯模块导出覆盖独立 Decimal golden、期间／汇率、成本去重、缺失冲突、来源 kind、不可变表图与敏感性边界。具体测试数与当前文件摘要以提交给 PMO 的回执为准；单模块通过不能替代 C0/API→DB→page、真实源取证或 Owner 实际使用。

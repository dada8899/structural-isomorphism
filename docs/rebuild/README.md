## 权威与公开边界

GitHub main 仍为生产代码权威。受控集成线只保存经审改造候选；共享模块从同一冻结 SHA 开发，最终发布 PR 重新通过当前 CI、独审和部署恢复门禁。规划提交或集成线绿色不等于上线。

本次公开快照只整理引用、移除本机绝对定位，并将已获授权的 B1 准入状态同步为当前检查点，不改变受审需求和技术边界。独审报告保留原始受审文件摘要；后续公开提交以真实 commit 身份另行追踪，不能把原始摘要冒充修改后文件摘要。

本地 Session 身份、故障现场、私有连接、账号标识、余额数值、用户记录、凭据和易变同步映射不随公开规划提交。清理须完整接管、核独有内容和依赖、验证必要恢复，再按精确清单执行；绝不以旧版号、文件名或访问失败推断无价值。

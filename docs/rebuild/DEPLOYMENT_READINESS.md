## 凭据与预充值边界

本会话现有 OpenRouter 环境入口已获 Mentor 明确项目调用授权。本轮仅执行官方 `GET /api/v1/key` 和 `GET /api/v1/credits`，均返回 200，确认凭据可认证并取得当前余额元数据。没有生成、嵌入、搜索等收费模型调用。

**余额数值仅保存在本 DevOps 会话私有输出的 `budget-readiness.json`，权限 600，不进入仓库或公开 Issue。** 本文件不保存密钥、账户标识或完整 API 响应。该回执是时点余额，不是已为本项目预留的额度。当前 key 未返回有限额度上限；自动充值、后付费状态、其他负载在途支出及项目共享账本仍未核实，因此不能将 API 可认证等同于费用硬边界已建立。

批准 VPS 上现有 DeepSeek 调用入口存在，静态审阅确认它通过既定凭据加载机制向固定 API 子进程注入密钥；现有路由只执行固定生成示例，没有余额查询分支。本轮没有执行该收费示例，也没有修改入口或新建凭据旁路。

收到 Mentor 的只读余额补充委派后，另核实既有本机批准挂载存在、类型为 FIFO、权限 600、归属当前用户；沿既定 dotenv 加载方式尝试只向单次 API 子进程注入指定密钥，以查询官方 `GET /user/balance`，禁止重定向和输出凭据。该次尝试在 27 秒期限到达前没有取得安全 API 回执。随后一次不发 API 请求的有界加载探针，确认挂载读取阶段在 8 秒内未完成。因此 DeepSeek 凭据可用性、余额和生产推理仍未验证；存在挂载文件不能证明挂载后端当前可供读取。超时及安全阶段标记保存在同一私有输出目录的 `deepseek-budget-readiness.json`，权限 600，不含密钥或完整账号配置。

先恢复或核实既定挂载后端，再按原入口做最小余额探针；本轮没有改动挂载、配置或权限。生产目标仍按既定 DeepSeek 方向验收，不因已有 OpenRouter 凭据静默更换目标或回退付费 OpenAI。该现场缺口只约束依赖真实调用的步骤，不阻断规格、离线开发或其他无关验证。

**合并若触发发布，必须同时满足发布门禁。** 发布 owner 先核当前 workflow、实际目标、环境保护和精确 SHA dispatcher 契约；必要的部署冻结作为有审查、有恢复的项目变更处理，不能删除 CI、空通过或绕过安全检查。

# 样例二 热系统与 RC 电路的公式对应

日期：2026-10-16；关联 F-004/006、A-002。以下为声明条件下的模型推导及验收设计，尚未通过产品符号/数值执行器或真实装置检验。

## 用户输入

“一个物体温度恢复到环境温度的过程，是否与电容放电对应？请比较公式，告诉我能借用什么、什么时候不能用。”

已读取 [MIT Unified Engineering 18.3 瞬态换热讲义](https://web.mit.edu/course/16/16.unified/www/FALL/thermodynamics/notes/node129.html)，其集总热参数推导与 RC 放电对比可作为本例直接出处；还读取了 [Aubrey Jaffer 的热模拟技术说明](https://people.csail.mit.edu/jaffer/Work/thermal)，该作者说明集总热节点可用电阻/电容网络表示。后者是作者个人技术资料，不能因托管域名而称为 MIT 官方研究结论。

## 对应卡的预期内容

令 `θ=T-T∞`，环境温度恒定，物体内部近似等温，热容和换热参数为正且不随状态变化、无额外热源，则：

```text
Cth·dθ/dt = -θ/Rth
Rth = 1/(hA)，Cth = m·cp，τth = Rth·Cth
```

孤立理想 RC 放电满足：

```text
Ce·dV/dt = -V/Re
τe = Re·Ce
```

| 热模型 | 电模型 | 映射所需说明 |
| --- | --- | --- |
| 温差 θ，K | 电压 V，V | 选择各自尺度后对应状态；单位并不相同 |
| 热流率，W | 电流，A | 对应传输速率，不宣称物理量相等 |
| 热阻 Rth，K/W | 电阻 Re，Ω | 正常数线性耗散关系 |
| 热容 Cth，J/K | 电容 Ce，F | 常数储存参数 |
| 时间常数 RthCth，s | 时间常数 ReCe，s | 两侧量纲均为时间 |

分别令 `x=θ/θ0`、`y=V/V0`，各自用 `s=t/τ` 无量纲化，且初值非零，则都满足 `du/ds=-u，u(0)=1`，解为 `u=e^(-s)`。这证明的是**给定理想化假设下两个模型的标准式相同**；并不证明任意实物都满足单节点模型。零初值使用未归一化方程，不能除以零。

规划算术核对得到 `s=0,1,2` 的解析值分别为 `1、0.3678794412、0.1353352832`；这是预期值计算，不是产品双侧数值求解或装置实验。

可借用时间常数、阶跃响应和一阶系统分析；真实参数需测量。若数据要拟合，应报告误差、采样范围和模型比较，不能把拟合好直接升级为物理机制已证实。

## 条件破坏与反例

| 反例 | 应有判断 |
| --- | --- |
| 物体表面和内部温度差明显 | 单节点热模型待拒绝，考虑分布模型/多节点；不能强配一个 RC |
| 环境温度随时间变化 | 温差方程多出环境变化项，不能直接套恒环境自由衰减 |
| 热源持续输入，或辐射非线性不可忽略 | 需带输入或非线性模型，原放电对应不完整 |
| 电路出现电感或明显非理想元件 | 原一阶模型不覆盖；不能只因仍出现指数项而宣称等价 |
| `R≤0` 或 `C≤0` | 不属于本例被动稳定模型的参数范围，拒绝该对应级别 |

## 验收任务

产品实际接收两侧原式与假设，输出标准式、映射、单位、边界和结论。独立执行者核符号变换，并在 `s=0,1,2` 比较归一化响应；数值允许误差由数值方法给出且记录，不能由模型随口编造。再运行至少一个上述条件破坏反例，系统必须降级为近似/不完整/不成立或信息不足，并说明理由。

成功不要求所有公式都有闭式解；要求诚实说明检查能力。未知函数、求导记号或无法解析的输入应提示澄清，不执行任意文本。用户保存对应卡后重开，原式、假设、参数和检查版本仍可追溯。

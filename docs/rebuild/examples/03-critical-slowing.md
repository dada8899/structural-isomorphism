# 样例三 临界减速预警的研究与反证

日期：2026-10-16；关联 F-005/006/007/008、A-003。当前已在规划研究中读取下列公开资料；**尚未由 Structure 产品运行研究任务、调用模型或复现论文实验**。

## 用户问题

“我发现某系统受到扰动后恢复变慢，波动也变大。能否用其他领域的临界减速理论判断它接近突变？需要什么证据，哪些情况下会误报？”

首先澄清系统对象、变量、采样频率、干预与观测、变化时间尺度、已知外部冲击。若用户只有主观描述，成果应是研究判断与数据计划，不能输出已经计算的预警分数或具体突变日期。

## 本次原文核查及支持边界

| 来源 | 本次访问情况 | 能支持的命题 |
| --- | --- | --- |
| Boettiger 与 Hastings，2012，[Quantifying Limits to Detection of Early Warning for Critical Transitions](https://arxiv.org/html/1204.6231)，arXiv:1204.6231v1 | 已读取 HTML 正文，重点核对摘要统计、零模型、ROC 比较及讨论 | 预警应评估误报与漏报；窗口、序列相关和零模型影响统计判断；示例中的性能不能当成任意系统保证 |
| Boettiger 与 Hastings，2012，[Early Warning Signals and the Prosecutor's Fallacy](https://arxiv.org/html/1210.1204)，对应 DOI 10.1098/rspb.2012.2085 | 已读取 HTML 正文，重点核对方法和讨论 | 事后按“发生崩溃”筛选序列可使预警统计出现选择偏差；不能把条件化历史表现直接当预测能力 |
| Dakos 等，2008，[Slowing down as an early warning signal for abrupt climate change](https://pubmed.ncbi.nlm.nih.gov/18787119/)，DOI 10.1073/pnas.0802430105 | 定位摘要与书目信息；PMC 正文入口本次出现浏览器验证页，未核全文 | 仅用来定位早期研究及其提出的方向，不据摘要复述全部方法或宣称已独立复现 |

前两篇不是“支持与反对”两个简单阵营：它们讨论机制适用性、统计识别和历史选择偏差等不同层次。结果应解释证据张力，而不是制造学术争论或用一篇负面文章推翻全部机制。

## 预期研究成果

报告先回答：恢复变慢可以形成候选机制，但单凭波动和相关性不能确认临界突变，也不能给普适预警阈值。把当前对象与来源领域的变量、扰动和恢复过程逐一映射，并指出缺失数据。

作为本例的数学说明，局部稳定平衡附近可提出 `dδx/dt=-kδx`，`k>0` 时恢复时间尺度为 `1/k`。在平衡、近线性、噪声平稳等额外假设下，相关性与方差可能随恢复速度改变。**该局部模型与当前对象是否一致仍待验证**，不能直接从公式推出真实业务、生态或市场系统即将崩溃。

竞争解释至少包括噪声强度变化、季节/趋势、外部驱动、采样与测量方式改变、事后选窗，以及恢复参数真正变化。研究产物应包含：原文证据表、命题与证据位置、模型和竞争解释、需要的数据、可执行且可停止的验证计划，以及未解决项。

若取得经授权的实际数据，可在预先说明的时间窗与处理规则下，比较局部恢复模型、稳定零模型和替代解释，并报告误报/漏报权衡；没有真实数据时只能输出“待检验计划”。合成数据实验必须标明合成，不能作为目标系统的实证结果。

## 从产品调用链验收

| 用例 | 必须观察到什么 |
| --- | --- |
| 正常研究 | 用户从问题发起任务；真实检索产生记录；原文被实际读取；结论可定位到资料与分析，报告保存可重开 |
| 无检索结果 | 明示检索范围和证据不足，不返回预置同题报告当真实研究 |
| 正文受限 | 标明摘要可读/全文未读；使用替代合法来源或限制结论，不绕过访问门禁 |
| 来源表面冲突 | 按对象、条件、方法和命题解释，保留无法解决的不一致 |
| 上游调用失败 | 保留已取得证据与阶段；可恢复且不重复计费/派发；失败不改为已完成 |
| 不支持的输入 | 用户仅说“感觉市场要崩”，系统请求可观察定义或给证据不足，不给投资预测 |
| 任务中断/取消 | 重开后状态与可靠检查点一致；说明在途调用与未知费用，不暗示已撤销 |

验收记录要含任务/attempt、输入修订、实际检索式、访问时间、来源 URL 和版本、读取范围、证据位置、分析方法与输入摘要、错误/重试及费用对账。不要把私密原文输入、凭据或可识别身份写入公开运行日志。

直接通用模型对照使用同题及同等资料许可；若基线只聊天而 Structure 可检索，须单列工具带来的差异。当前没有执行该对照，也没有“优于通用模型”结论。

## P0 — 阻断发布（按主题去重合并，共 7 组）

### 组 1｜核心流程断裂：报告存了等于没存
- **My Reports 永远是空的** + **`/api/report/{id}` 对真实报告 404**（usability P0-1/P0-3，同根）。persist 时 anon-id 没正确落库，导致用户生成的报告全站找不回。
- **分享页渲染降级**：`report.js` 用通用键值树 dump，分享链接打开看到的是 `if_time_short`、`this_week` 等**原始英文字段名**，不是给人看的报告（usability P0-2）。
- → 性质：真 bug，可由 agent 修。修 anon-id 落库一处，连带解决两个 P0。

### 组 2｜信息架构 + 上线即 404
- **线上 beta 只部署了 home/analyze/report 三页**，其余 7 页（reports/classes/discoveries/papers/learn/methods/about）**线上全部 404**（design 大发现）。导航点了就 404。
- **两套首页并存**：部署的首页是问答 UI（`ask.js`），而文档/代码里「搜索→结果→选现象」流程挂在一套**无任何入口的旧首页**（`home.js`/`search.html`）（usability P0-4）。
- → 性质：**需产品决策**——7 页补部署 or 从导航删；两套首页保留哪套。

### 组 3｜移动端不可用
- **移动端完全没有站点导航**：≤480px 时 nav link 全 `display:none`，又无汉堡菜单兜底，手机用户只能看 logo（design P0-1）。
- → 性质：可由 agent 修（加汉堡菜单）。

### 组 4｜钱与安全（技术红线）
- **LLM 成本无每日熔断**：`BudgetExceeded` 异常定义了从不 raise，匿名用户可无限烧 Claude/DeepSeek（launch P0-1）。
- **限流形同虚设**：匿名流量被打成 "free" tier 走 60/min 而非 5/min，放大上一条（launch P1，与 P0 同组处理）。
- **完全没有安全响应头**：无 HSTS/X-Frame-Options/X-Content-Type-Options/CSP/Referrer-Policy（launch P0-2）。
- → 性质：可由 agent 修。

### 组 5｜错误处理外露
- **API 失败把原始报错丢给用户**：discoveries 页直接显示 `Unexpected token '<'... is not valid JSON`（design P0-4）。
- **LLM 失败 `str(e)` 直接回显**用户（launch P1）。
- **report 错误页缺页头页脚**，整页一张报错卡 + 大片空白，像「崩了」（design P0-3）。
- → 性质：可由 agent 修。

### 组 6｜文案：可信度与一致性
- **一概念三种叫法**：共享模式 / 普适类 / 等价类 / universality classes 混用（copy P0-1）。
- **核心数字自相矛盾**：首页「39 个发现」vs about「63 个」；实证系统 5 vs 13（copy P0-3）。对外宣称的数字打架。
- **`/start-here` 整页英文**：导航第一项、定位「10 分钟看懂」的引流页却纯英文（copy P0-2）。
- → 性质：统一术语/数字可由 agent 修，但**真实数字需事实核对**；start-here 需重写。

### 组 7｜产品定位与价值兑现
- **首屏定位摆错擂台**：「跨学科搜索引擎」把产品摆到 Perplexity 必输的位置，且与「3 分钟出报告」不符（copy P0-4 + product P0-1）。项目自己的 SESSION-13 早想清楚卖点是「验证+迁移」，首屏一字未改。
- **无 out-of-scope 拒答门**：「1+1 等于几」照样硬生成报告——验证型产品硬拗 = 信任崩（product P0-2）。
- **无等待预期管理**：完整报告 >3 分钟，全站没有一句「约需 3 分钟」（product P0-3）。
- → 性质：定位句**需用户拍板/出声音**；拒答门 + 等待文案可由 agent 修。

## P1 — 强烈建议发布前修（择要）

- 主导航全站无「我的报告」入口；导航项跨页 5/8/面包屑 三种不一致。
- `report.html`/`reports.html` 的 Plausible 指向错误域名；KaTeX 走 CDN（违反全站自托管策略）。
- 报告加载文案承诺「30–60s」，实测 >180s——预期严重不符。
- 报告生成流偶发零字节返回，可能停在 loading 永不报错。
- `/docs` `/openapi.json` 在 prod 公开；`HEAD /` 返回 405；beta `robots` 允许搜索引擎收录。
- 缺隐私政策页（后端有 GDPR 删除接口，前端无入口）。
- learn 页多处空白卡片；收藏徽标裸露「0」；classes 信息密度过高缺留白。
- 专业术语零解释（结构同构/等价类/幂律/元问题/LLM）；中英混杂散落全站。
- citations 段真实性需核查（防 LLM 编造文献）。
- PASS/FAIL 可信度资产（最强差异化）被藏着没在产品里露出。

完整 P1/P2 见 5 份分报告。

# Structure 改造首版需求与验收草稿

版本：0.2；日期：2026-10-16；负责人：Product Manager；状态：**Mentor 已正式准入受限 B1；三能力实现待共享契约冻结**。确认依据为 用户确认与 [Space 需求权威页](https://chatgpt.com/space/page_1cfcb3669b7881919ef320608251e8c6)。本文是本地执行规格；本轮 Astra 完整规划初读未发现产品与样例方向硬伤，需求权威同步、审阅基线登记和正式准入由 Mentor 负责，不代表全产品已实现或验收。

## 本版要交付什么

用户把一个现象交给 Structure，能够找到值得比较的跨领域模型，查看公式、来源和适用条件，把来源领域的方法转译成当前问题的可验证方案，再将值得追查的候选升级为真实研究任务。结果可以保存、重开、修订和回访。**本版同时覆盖现象解题、公式对应、深度研究，三者共享研究记录和证据，不拆成三个互不相通的工具。**

首发用户采用项目 Owner 本人及类似的产品经理、跨领域研究者作为可逆默认，尚无访谈或真实使用证据。首批覆盖排队与流量、线性一阶储存与耗散、局部稳定性与恢复速度三个模型家族。该选择用于验证完整能力，不声称覆盖任意现象；新领域可得到“暂未找到可靠对应”和可行动的补证建议。

本版不承诺自动证明任意公式、保证迁移奏效、发现世界首次成果，或运行用户/模型任意生成的代码；不扩建投资预测、商业套餐、团队协作和通用自动化平台。实际数据分析仅使用经过审查的有限方法与输入，不通过增加报告篇幅代替取证。

现有代码已有结构草案、候选检索、映射、报告保存和账户边界，可按实测复用。但 `web/backend/services/deep_report.py` 将来源限定为内部 KB、文献状态限定为未检索；`services/cost_ledger.py` 只做单进程请求次数计数。本版需要真实外部取证与持久共享预算，不能只修改这些状态文案。公式候选字段也不构成符号或数值验证能力。

## 一条连续的用户流程

首页提供“研究一个现象”和“比较公式”两个入口，进入同一研究空间。“我的研究”找回已有任务，资料库辅助浏览，实验功能不抢占主导航。用户不必理解 Git、模型供应商或数学术语才能开始。

| 用户动作 | 系统回应 | 用户下一步 |
| --- | --- | --- |
| 描述现象、希望解释或改变的结果 | 区分观察与推测，给出可编辑结构草案；只问影响候选选择的缺失信息 | 确认或修改变量、边界与未知 |
| 确认结构 | 呈现候选及“为什么相关、哪里不同、证据到哪一步” | 选择候选、排除或补充信息 |
| 查看候选或输入公式 | 显示公式、映射、假设、出处及检查结果 | 比较模型，查看可迁移方法 |
| 采用一种思路 | 给出已有方法的证据、迁移条件和最小验证 | 保存方案或发起深度研究 |
| 发起深度研究 | 告知范围、可用预算、实际执行阶段和停止入口 | 跟踪、取消、恢复或查看成果 |
| 查看研究成果 | 结论与来源、计算、反证和未解决项对应 | 修订问题，记录实验与结果 |

修改问题结构会产生新修订；旧报告保留原问题和来源版本，不被悄悄改写。切换模型或重试产生新 attempt，不把历史成功拼成当前结果。长任务在离开页面后是否继续由真实执行状态决定，界面不得无依据承诺后台完成。

## 核心需求

| 编号 | 用户可观察要求 | 关键验收 |
| --- | --- | --- |
| F-001 问题澄清 | 输入现象与目标，确认变量、约束、时间尺度、已有数据和未知；可跳过非必要资料 | 区分事实与因果猜测；缺信息时不强行指定唯一机制；修改后旧结果标为历史 |
| F-002 跨域候选 | 给出可追溯候选与差异；排序分数仅表示检索相关度 | 候选领域不同且映射有实质内容；同词反例不会因高相似度被标同构；无匹配状态可继续补证 |
| F-003 方法迁移 | 查明原领域方法、证据支持范围和前提，再解释当前情境的调整、代价和最小实验 | 模型适配、来源方法有效、迁移有效分别登记；没有查到出处时只能作为待证提议，不称成熟解法 |
| F-004 公式对应 | 输入两侧公式或从现象进入；展示符号、单位、参数范围、变换和边界 | 区分代数恒等、在声明条件下模型等价、近似、部分相似、不成立、信息不足；数值一致不等于全局证明 |
| F-005 深度研究 | 用实际产品调用链检索外部资料、读取原文、比较竞争解释，必要时执行受控分析 | 每个结论绑定真实取得的资料位置或计算；保留检索范围和日期；缺文献/原文受限不能伪装完整综述 |
| F-006 我的研究 | 保存问题修订、候选、公式检查、来源、任务和结果；重开可继续 | 服务重启及页面重开后内容与状态一致；匿名内容和账户内容边界明确；跨账户拒绝访问 |
| F-007 验证与回访 | 记录实验计划、操作、观测、反例和结论修订 | 计划、运行、结果分列；拒绝或未支持的候选仍保留原因，不只累积成功记录 |
| F-008 成本与恢复 | 启动前说明研究范围与预算约束，显示执行状态、失败与可行动选择 | 持久化共享账本覆盖并发/重试；已知费用、预留和未对账分别显示；余额不可核实则不发付费调用 |

### 公式与证据的统一表达

公式检查至少包含两侧原式及出处、标准式、变量单位、变换步骤、参数与边界条件、检查方式和结果。系统只能在明确声明的模型与检查范围内给结论。“两模型在条件下等价”不等于“现实系统已验证相同”。来源领域不具备同一假设时允许保留启发，但必须降低对应级别并说明不迁移的部分。

证据类型分别记录：用户提供的观察、内部候选记录、外部原文、符号检查、数值计算、模拟结果、真实观测和独立评审。一个来源只支持它实际讨论的命题；题目或摘要可访问而正文不可访问时必须标明。来源冲突呈现各自对象、条件和方法，不以多数票或模型口吻消除冲突。任何“已验证”状态都要能打开具体检查记录。

## 深度研究的状态与失败行为

任务状态为待执行、取证中、分析中、整理中，以及完成、证据不足、失败、已取消之一。暂停恢复必须有持久化检查点和已完成步骤；状态不能只存在浏览器内。以下是行为要求，具体接口和存储由架构契约定义。

| 场景 | 必须发生的行为 |
| --- | --- |
| 无结果或来源不适用 | 返回检索范围、证据不足及下一补证；不能用内部候选伪装外部结果 |
| 来源冲突 | 生成冲突表并限制结论；允许任务以条件化结论完成 |
| 检索、正文访问或模型失败 | 保留已经取得的资料与阶段，说明失败处；重试不得重复展示旧生成结果为新结果 |
| 计算输入越界或假设不满足 | 不执行不适用方法，指出缺失条件；不让模型绕过允许范围 |
| 用户取消 | 不再派发新步骤；在途调用按真实可取消性说明，费用待对账；保留已获结果 |
| 服务重启或回执不明 | 回到最后可靠检查点；先对账在途动作，不盲重放；不能自动将未知费用释放为余额 |
| 余额不足或计费边界不明 | 停止对应付费步骤，保留任务及已有证据；不充值、不透支、不静默换供应商 |

结果可以包含明确标注的阶段笔记，完整报告在来源及结构校验后发布；部分生成文本不得带“研究已完成”的外观。每一步显示当前做什么、已经拿到什么、用户能做什么；不显示内部堆栈或私有配置。

## 账户、数据与费用

用户主动保存的研究默认私有。分享是明确动作，可撤销，并只公开用户选定的结果；未分享的原始输入、附件、令牌和身份信息不出现在 URL、公开页或运行日志中。登出、失效会话和跨账户请求不得读到私有研究；匿名转账户沿用已审身份契约，不因重构重新暴露已认领报告。

账户删除或研究访问权被撤销时，正在运行的研究应失去后续读取、发布和保存到该账户的资格；迟到结果、自动重试、服务重启和恢复检查点均不能重新创建已删除资产或恢复旧分享权限。界面清楚显示访问已终止；尚在途且不可取消的外部调用不承诺已撤销，已经发生或回执不明的费用保留必要、不含已删研究正文的对账状态，不重复扣费，也不以资产删除伪装费用归零。

外部查询只传递研究必要信息；含敏感内容时先让用户选择删减或不外发。用户可查看保存范围、导出和删除自己的研究。旧账户和记录按已授权的接管清单核实去留，不能仅按最后访问日期删除；迁移保留所有权与分享边界，清理前验证必要恢复。

用户已授权在现有预充值范围内执行项目，应用不额外设一个未经同意的固定总金额。但实施仍须核实可用余额、自动充值/后付费状态、调用价格与共享账本。任务实际消耗、在途预留与项目余额关联，跨进程、并发和重启不重复释放；无法估计上限的调用不能无约束运行。尚未具备账户与费用实测，不是用户未授权。

## 页面与信息优先级

研究空间按“问题—候选—模型与方法—证据—验证”组织；首屏先显示当前结论或任务状态、证据级别和下一动作，再展开推导与运行细节。公式提供数学表示和大白话解释，单位和条件不能藏在展开内容之外。窄屏可以顺序阅读候选与映射，不要求横向拖动才能看关键差异。键盘可完成核心操作，运行状态和错误有可读文本；具体设计复用既有组件，独立验收记录实际设备范围。

## 旧功能去留与兼容

以下是首版产品决策建议，具体删除对象由接管及依赖证据闭合后执行；不存在的使用数据不能当“没人用”。

| 现有内容 | 本版处理 | 兼容要求 |
| --- | --- | --- |
| Ask、Search、Analyze、Mapping | 整合为主研究流程，复用可用能力 | 保留旧报告可读；旧查询入口正确引导且不把私密输入放 URL |
| Reports、History、Favorites、反馈 | 合并为我的研究与验证记录 | 保留所有权、原报告版本、分享撤销和删除语义 |
| Discoveries、Classes、Phenomenon、Papers | 作为候选与证据资料库 | 旧链接有映射或明确说明；候选不能升级成已验证科学结论 |
| Apply、Stress-test、Lint、Diagnose | 有用能力进入模型检查与迁移步骤，不必各占主导航 | 先核公共 API/使用与数据；退场给解释，不悄悄返回不同语义 |
| Whitespace、Connections、Daily、Insights | 实验区保留必要内容，首版不扩张 | 完成引用与依赖核对后决定整合或下线 |
| Phase Detector、公司与市场回测 | 作为独立实验研究入口保留 | 标明冻结数据与负结果，不承诺实时预测；共享账户不能破坏 |
| Billing、Pricing、Checkout mock、Newsletter/Waitlist | 不扩建商业化；mock 不作为真实收费路径 | 保留实际订阅与必要退订边界；无真实功能的公开承诺收敛 |
| Python 包、MCP、公开 API、论文与数据集 | 保留资产，按主产品实际依赖决定维护面 | 独立版本/链接/许可核查后才能退役；不批量删除历史 |

## 验收与开发准入

三个基准样例见子文档。每条都有正常输入、预期、失败与证据；它们是规格示例，不是产品通过证据。实现后由独立执行者通过实际页面和产品接口运行，额外为每条加入至少两个未用作开发固定答案的输入变体，并覆盖该条反例。变体数是首轮检查规模，不是统计效果结论；新证据决定是否扩展。

| 验收编号 | 通过条件 | 失败条件 |
| --- | --- | --- |
| A-001 现象解题 | 真实输入得到跨域模型、可追溯方法、条件化迁移与最小验证；单位和计算一致 | 只给相似故事、无依据成熟方法、混淆相关与因果、越界套模型 |
| A-002 公式对应 | 正常式给出可检查变换；假设破坏的反例降级或拒绝；保留检查范围 | 只换符号、忽略单位/边界、以数值拟合冒充证明 |
| A-003 深度研究 | 产品链真实检索并核查原文，结论有证据位置，展示反证；无结果/冲突/调用失败路径成立 | 预置报告冒充运行、只有搜索摘要、捏造引文、无条件宣布机制或新颖性 |
| A-004 保存与权限 | 保存重开、服务重启、任务恢复、取消对账、旧报告与跨账户隔离通过；运行中删除账户或撤权后，迟到结果/重试/重启均不能复活资产或权限，已发生与未知费用仍可正确对账 | 内容丢失、重复收费、私有数据泄露、未知任务误标完成、删除后重新生成私有资产或错误恢复分享 |
| A-005 清理与运行 | 功能去留、旧链接、数据迁移/清理、必要备份恢复和目标环境重复任务有证据 | 仅 HTTP 200、页面可开或删除数量被当作完成 |

同题通用模型对照在相同原始输入、允许资料范围和近似成本/时间条件下进行，记录模型与版本、检索许可、输入输出、消耗和人工评判。两边工具条件不同时分列解释，不能归因为 Structure 本身。比较候选有效性、来源准确性、数学错误、边界识别和下一行动可用性；任何虚构来源或关键数学错误先修复，不能用平均分抵消。当前未调用付费模型，未执行该对照，尚无价值提升结论。

**本轮开发准入只覆盖 B1 Bootstrap、共享契约实现及离线风险探针**，包括最小骨架、正式导出、受控输入/输出边界、持久状态与恢复/撤权反例、离线合法对照及必要 CI。Astra 初读意见允许在需求权威同步和审阅基线登记后进入该受限范围；Mentor 已正式准入该受限范围，不自动派发后续模块。

三项产品能力的并行实现须等待共享正式消费者以真实导出完成生命周期验证、契约 revision 冻结、独立审阅及当前候选必要 CI 通过。来源和公式检查的允许范围、预算硬边界和恢复方案、旧功能及数据接管责任均需明确；不能用形状合法的 mock 或本文样例代替消费者验证。

真实付费接入、生产运行预算、数据迁移/清理和发布分别满足其现场余额、计费边界、凭据、具体处置验证与恢复前置。余额未验不阻断无依赖的 B1 离线工作，也不解除付费或生产门禁。发布观察窗口、服务指标及资源限制由 PMO/DevOps 根据实测登记，未确定前不宣称稳定服务已验收。技术交付后仍登记“待用户实际使用”，用户真实反馈不能由 Agent 代签。

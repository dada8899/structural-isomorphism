What this paper does
--------------------

This paper synthesizes the Structural Isomorphism Project's first five
validation phases into a single cross-domain test of self-organized
criticality (SOC) universality. The same Python pipeline -- assembled
from the standard Clauset-Shalizi-Newman 2009 MLE power-law toolkit
plus Vuong lognormal-vs-exponential likelihood ratio and Omori-Utsu
temporal stacking -- is applied unchanged to four real systems
(USGS tectonic earthquakes; S&P 500 daily returns 1990-2025; three DeFi
lending protocols, namely Aave V2, Compound V2, MakerDAO; mouse-cortex
neural avalanches from DANDI 000006) and to four synthetic non-SOC
nulls (folded normal, exponential, Poisson inter-arrival, Poisson
Omori). The pipeline recovers canonical exponents on the real systems
and rejects all four nulls -- ruling out the trivial "fits everything
as a power law" failure mode that has historically dogged SOC claims.

Three honest caveats are reported in §6 (lognormal is not rejected in
every raw-tail test; the pipeline detects endogenous threshold-cascade
signatures only; the project's downstream cross-domain predictions
remain unverified).


Why arXiv (and why cross-listed across three categories)
--------------------------------------------------------

The pipeline crosses three of arXiv's traditional disciplinary
boundaries -- statistical physics, finance, and neuroscience. We
believe the cross-listing is essential rather than ornamental: the
paper's central methodological claim ("one fixed pipeline, no
per-domain tuning") only makes sense if reviewers from each domain can
see the test on their own data with the same code path. We have
therefore selected physics.soc-ph as primary (since the universality-
class framework is the unifying methodological backbone), with q-fin.ST
and q-bio.NC as cross-lists for the Phase 2/3 finance and Phase 4
neuroscience sections respectively.


Replicability
-------------

Every number in the paper is reproducible from the public dataset
deposit:

  - GitHub:  https://github.com/dada8899/structural-isomorphism (MIT)
  - Zenodo:  10.5281/zenodo.XXXXXXX  [to be filled after deposit]
  - PyPI:    soc-pipeline 0.1.0      [planned, MIT]

The Zenodo deposit (44 MB tarball, 521 files) bundles:
  - per-system raw inputs and fit results for 13 systems + 4 nulls
  - the B1/B3 multi-model LLM ensemble critic outputs over a
    21-candidate universality-class taxonomy (B3 taxonomy v2)
  - the pipeline source code snapshot (~1,595 LOC, MIT)
  - SHA-256 manifest of every file in the bundle

A reproducibility checklist runs through the canonical Phase 1-5
numbers and is included in Appendix A of the paper.

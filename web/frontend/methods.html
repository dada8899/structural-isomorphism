共享分析模块，不同证据结果

共享代码只能保证分析步骤可比较，不能保证数据独立、机制相同或结论成立。这里记录从候选模式到真实/合成数据测试的流程，并保留支持、拒绝、NULL、PARTIAL 和 INCONCLUSIVE 结果。

1)
现象收集 / 图构建
读取前几代检索中带 A、B+ 内部评分标签的候选，按当时阈值过滤，得到 180 节点 / 143 边的现象关联图；标签不代表正确性或证据质量。
2)
社区发现
用社区发现算法(Louvain)在关联图上聚簇,得到 23 个候选等价类,21 个跨 ≥ 2 领域。
3)
匹配到已知模式
把算法生成的候选分组关联到文献中的命名模式，作为待检验的分类假设；关联标签不等于确认物理普适类或共享机制。
4)
预测翻译
参考文献中报告的关系草拟跨领域可证伪假设；每项迁移仍需核对变量映射、数据、替代解释和失败标准。
5)
领域结果记录（真实与合成数据）
共享分析模块用于多份领域数据和合成对照。结果并不一致：有支持、拒绝、部分支持、NULL 和证据不足。合成对照检验代码行为，不替代真实系统的机制证据。

共享代码模块

多份领域记录复用一个 Python 分析模块（查看代码 →）；数据接入、预处理和运行配置仍需逐项审计。模块提供以下分析操作：

  • 幂律拟合 — Clauset-Shalizi-Newman 2009 最大似然估计。
  • 置信区间 — Bootstrap 95% CI。
  • 对照假设比较 — Vuong 似然比,对比对数正态、指数分布。
  • 余震时间衰减 — Omori-Utsu 律(适用临界级联)。
  • 合成数据对照 — 匹配样本量的合成数据(高斯随机游走、指数、Poisson 事件、Poisson 余震)。
  • 贝叶斯模型选择 — 对数 binned BIC,幂律 + cutoff vs 对数正态。

不同领域复用共享分析模块，但数据接入、预处理和适用参数可能因数据而异。复用提高可比性；在缺少逐项配置与来源审计时，不能声称整条管道完全未修改、未调参或未使用先验。

对照组与共享形态对照

为检查代码是否会把明显的非幂律样本也拟合成幂律，我们记录了 4 个合成对照（Gaussian 随机游走、指数变量、Poisson 事件、Poisson 余震叠加）。在当时配置下这些样本未被选为幂律（记录的 R ∈ [-45, -16]，Poisson 余震 R² ≈ 0.002）。这个小型对照只覆盖已选生成过程，不能排除其他方法偏差。

另有一份探索性形态对照：在有限尺寸标度假设和既定归一化下，7 份领域曲线记录 rshape = 1.11；当时的模型选择在 5/7 中偏向幂律 + 指数 cutoff。阈值、领域选择和预处理均非预注册，因此这只是候选观察，不能证明 7 个领域发生同一 collapse 或共享机制。

查看数学结构

有限尺寸标度形式: P(s) = s-α f(s/s*),其中 f 为归一化形状函数。形态崩塌评价指标 rshape 计算 7 个领域归一化曲线的形状偏差。

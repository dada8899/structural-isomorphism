## User-action submission flow (per the in-bundle README)

The 11-step `release/arxiv/c1-unified-preprint-v0.4/README.md` is authoritative — read
it before submitting. The compressed form:

1. Log in to arXiv → New submission → arXiv non-exclusive licence.
2. Upload a `.zip` of `main.tex` + `references.bib` (no figures in v0.4).
3. Verify server-side compiled PDF renders: title, abstract, 50 refs, tables 1/2/A1–A4.
4. Paste form metadata:
   - Title: *A pipeline for cross-domain validation of self-organized criticality: completing the taxonomy*
   - Primary category: `physics.soc-ph`
   - Cross-list: `q-fin.ST`, `q-bio.NC`, `cond-mat.stat-mech`
   - MSC: 62-07, 82C99, 86A15
5. Abstract: paste `abstract.txt` content.
6. Comments: per in-bundle README §5 (mention companion Zenodo DOI + github URL).
7. Cover letter content → Submission notes field.
8. Preview → Submit → moderation queue (1–3 working days).

Estimated user time: **~15 minutes** active, plus moderation wait.

## Classification advice (re-confirm at submission time)

The current C1 primary category in the in-bundle README is **`physics.soc-ph`**
(physics and society). That choice was deliberate in SESSION-23: it best reflects the
cross-system framing (universality across physical + biological + socio-economic
domains). However:

- **First-time submitters to `physics.soc-ph` require arXiv endorsement.** Check status
  at https://arxiv.org/auth/endorse *before* starting the submission, not during.
- **Alternative primary:** `physics.data-an` (data analysis, statistics) is a more
  conservative classification with no first-time endorsement requirement; cross-list
  `q-bio.QM`, `cond-mat.stat-mech`, `q-fin.ST` to keep cross-domain reach. This is the
  fallback if endorsement is not in hand at submission time.
- **Triple-submission consistency:** the methodology short-note targets `cs.LG +
  stat.ME`; the C4 paper targets `cs.LG + stat.ME + cond-mat.stat-mech +
  physics.data-an + q-bio.QM`. C1 with primary `physics.soc-ph` therefore differentiates
  itself, which helps reviewers and arXiv discovery treat the three preprints as
  related-but-distinct rather than as duplicates.

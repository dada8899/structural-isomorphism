## Honest framing (not a recommendation)

This bundle is **prepared materials, not a strategic recommendation**. The decision to submit three preprints simultaneously vs. submit C1 alone and wait for reviewer feedback before the other two is **the author's**.

- Pro of triple-submission: 3 arXiv IDs at once, cross-citation network, avoids the 4-6 week wait.
- Con of triple-submission: reviewer perception of fragmentation; methods note may be too thin (~5 pages); C4 hasn't had standalone reviewer vet.

`TRIPLE-SUBMISSION-PLAN.md` discusses both sides honestly. A reasonable alternative is to submit C1 alone first, take 4-6 weeks of reviewer feedback, then revisit C4 and the methods note. That path is a strict subset of this bundle — the C1 submission step is identical; the rest is paused.

## Pre-submission edits required (per submission)

Each preprint references the others by intended arXiv ID. These `[PENDING_*_ARXIV_ID]` placeholders need to be substituted before each submission, or arXiv `replace` will need to be used after the fact:

| Placeholder | Lives in | Substitute when |
|---|---|---|
| `[PENDING_C1_ARXIV_ID]` | `c4-arxiv-bundle/metadata.yml` `comments:` field | After C1 arXiv ID is issued |
| `[PENDING_C1_ARXIV_ID]` | `methodology-short-note/main.md` §7 ref [1] | After C1 arXiv ID is issued |
| `[PENDING_C4_ARXIV_ID]` | `methodology-short-note/main.md` §7 ref [22] | After C4 arXiv ID is issued |
| `[PENDING_ZENODO_DOI]` | various | After Zenodo deposit is minted (optional) |

If submitting all three in a single afternoon, do the substitutions in the order C1 → C4 → methods, each within ~1 hour of the previous submission's ID being issued.

## After all three IDs are in hand

1. Top-level `README.md` and `CITATION.cff`: add all three arXiv badges + identifiers.
2. Each preprint can be updated via arXiv `replace` if a placeholder remained at submission time (low-cost, normal arXiv operation; preserves v1 / v2 history).
3. The C4 + methods cross-references back to C1 should be live by the time press / outreach is considered.
